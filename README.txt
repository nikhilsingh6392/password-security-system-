PASSWORD SECURITY CHECKER — SENTINEL
=====================================

FILES
- index.html: page structure
- style.css: responsive dark cybersecurity design
- script.js: local analysis and secure password generator
- report/Project-Report.pdf: editable-details academic report draft
- presentation/Project-Presentation.pptx: presentation draft

RUN
1. Extract this folder.
2. Open index.html in a modern browser, or open the folder in VS Code and use Live Server.
3. Enter a test password in the analyzer.
4. Adjust generator options and click Generate Password.

IMPORTANT
- Password analysis is performed locally in the browser.
- Generated passwords use the Web Crypto API.
- The score and entropy are simplified educational estimates, not a guarantee of security.
- Fill in your name, roll number, guide, institution and academic session in the report and slides.
- Add your own screenshots and actual test results before submission.
